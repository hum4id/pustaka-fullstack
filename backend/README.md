# Pustaka — Backend (NestJS)

Backend REST API untuk katalog buku Pustaka. Struktur MVC: Entity (model), Controller (endpoint HTTP), Service (logika CRUD, data disimpan sementara di array memori).

```bash
npm install
npm run start:dev   # http://localhost:3001/api
```

Uji endpoint dengan ekstensi VS Code **REST Client** memakai berkas [`buku.http`](./buku.http). Dokumentasi lengkap ada di README repository (folder induk) dan laporan di `docs/`.
